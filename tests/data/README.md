# Test photos

`victory.jpg`, `pointing_up.jpg`, `fist.jpg` and `thumb_up.jpg` are MediaPipe's
own test images, from `https://storage.googleapis.com/mediapipe-assets/`
(the MediaPipe project, Apache License 2.0). `tests/test_hand_pose.py` runs
them through the real hand model to check how poses are read.
